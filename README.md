# E-Commerce Sales Analysis Dashboard

This is my first Data Analytics project, where I used Microsoft Excel to analyze e-commerce sales data and build an interactive dashboard.

The main goal of this project was to understand how sales were performing across different products, categories, cities, months, and payment methods.

## What I worked on

- Cleaned and organized the sales data in Excel
- Created PivotTables to summarize the data
- Created PivotCharts to visualize the results
- Added Slicers to make the dashboard interactive
- Created KPI cards for important metrics like revenue, orders, items sold, and average order value
- Compared sales across categories, cities, products, months, and payment methods

## Dashboard

The dashboard shows:

- Total Revenue
- Total Orders
- Total Items Sold
- Average Order Value
- Revenue by Category
- Monthly Revenue
- Revenue by City
- Payment Method
- Top Selling Products

The dashboard can also be filtered using Slicers for different categories, cities, and payment methods.

## Some Insights I Found

- Electronics generated the highest revenue in the dataset.
- Chandigarh was the highest-revenue city.
- February had the highest monthly revenue.
- Cheese was the top-selling product by quantity.
- Card was the most used payment method.

Overall, the dataset generated ₹599,550 in revenue from 15 orders, with 27 items sold.
